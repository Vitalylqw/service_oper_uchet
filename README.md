# 📊 Система Учета Операций

Система для автоматического парсинга Excel файлов с данными о продажах и загрузки их в MS SQL Server базу данных.

## 🎯 Возможности

- ✅ **Парсинг Excel файлов** со сложной структурой мастер/подчиненные записи
- ✅ **Надежная обработка ошибок** с детальной статистикой
- ✅ **Автоматический расчет** финансовых показателей (выручка, маржа, стоимость)
- ✅ **Поддержка MS SQL Server** для хранения данных
- ✅ **FastAPI веб-интерфейс** для управления
- ✅ **Полное логирование** всех операций

## 🏗️ Архитектура

Проект следует принципам **Domain Driven Design (DDD)**:

```
src/
├── domain/           # Бизнес-логика и модели предметной области
├── application/      # Сценарии использования
├── infrastructure/   # Внешние сервисы (БД, файлы)
└── presentation/     # API и пользовательские интерфейсы
```


## 📁 Структура Данных

### Excel Файл

Система обрабатывает Excel файлы со следующей структурой:

- **Лист 1**: "Май 2025" 
- **Лист 2**: "Июнь 2025"
- **Строка 2**: Заголовки колонок
- **Строка 3+**: Данные

### Колонки

| Колонка | Описание | Тип |
|---------|----------|-----|
| Клиент | Название клиента (только в мастер-записи) | str |
| Номенклатура | Информация о счете или наименование товара | str |
| Кол/Отгр? | Количество товара или статус отгрузки | float/str |
| Цена вх/накл | Цена закупки или статус УПД | float/str |
| цена исх/Оплач? | Цена продажи или статус оплаты | float/str |
| Выручка | Выручка по позиции/сделке | float |
| Маржа | Маржа по позиции/сделке | float |
| От кого Зак/Прод | Продавец | str |
| Ст. Закупки | Стоимость закупки | float |
| Поставщик/Откат | Поставщик или сумма отката | str/float |
| дата забора | Дата забора товара | str |

## 🐛 Обработка Ошибок

Система имеет многоуровневую обработку ошибок:

- **Уровень файла**: несуществующие файлы, поврежденные Excel
- **Уровень листа**: пустые листы, некорректные заголовки  
- **Уровень сделки**: поврежденные мастер-записи
- **Уровень позиции**: неполные данные товаров
- **Уровень расчетов**: ошибки в математических операциях

При любых ошибках парсер продолжает работу, заполняя отсутствующие данные значениями по умолчанию и записывая подробную информацию в лог.

## 📝 Логирование

Все операции логируются с использованием стандартной библиотеки `logging`:

- **INFO**: Основные этапы парсинга
- **WARNING**: Предупреждения о некорректных данных
- **ERROR**: Критические ошибки с трассировкой
