## 🎯 ОБЗОР СИСТЕМЫ

**Service Oper Uchet** - это веб-система для автоматической синхронизации данных о продажах из Excel файлов в базу данных с возможностью просмотра, анализа и управления информацией.

### Основные возможности

- 📤 **Загрузка Excel файлов** с данными о продажах
- 🔄 **Автоматическая синхронизация** с базой данных
- 📊 **Просмотр и анализ** сделок и статистики
- 🔍 **Поиск и фильтрация** данных
- 📈 **Мониторинг** процесса синхронизации
- 🔐 **Безопасный доступ** с ролевой системой

---

## 🚀 БЫСТРЫЙ СТАРТ

### 1. Вход в систему

1. Откройте браузер и перейдите по адресу: `http://localhost:3000`
2. На странице входа введите ваши учетные данные:

| Роль | Логин | Пароль | Возможности |
|------|-------|--------|-------------|

### 2. Главная страница (Dashboard)

После входа вы увидите главную страницу с:

- 🔄 **Статус синхронизации** - информация о последней синхронизации
- 📈 **Графики** - визуализация данных

## 📤 ЗАГРУЗКА И СИНХРОНИЗАЦИЯ ФАЙЛОВ

### Подготовка Excel файла

Система поддерживает Excel файлы (.xlsx, .xls) со следующей структурой:

| Столбец | Описание | Обязательный |
|---------|----------|--------------|
| **A** | Номер счета | Да |
| **B** | Дата счета | Да |
| **C** | Клиент | Да |
| **D** | Продавец | Да |
| **E** | Товар/услуга | Да |
| **F** | Количество | Да |
| **G** | Цена за единицу | Да |
| **H** | Сумма | Да |

### Загрузка файла (для аналитиков и администраторов)

1. Перейдите на вкладку **"Синхронизация"**
2. Нажмите кнопку **"Выбрать файл"**
3. Выберите ваш Excel файл
4. Нажмите **"Загрузить"**

### Мониторинг процесса

После загрузки файла:

1. **Статус "Ожидание"** - файл принят и поставлен в очередь
2. **Статус "Обработка"** - файл анализируется и сравнивается с существующими данными
3. **Статус "Завершено"** - синхронизация успешно завершена

### Результаты синхронизации

После завершения вы увидите:

- ✅ **Количество новых сделок** - добавлено в систему
- 🔄 **Количество обновлений** - изменено существующих записей
- ❌ **Количество удалений** - удалено из системы
- ⚠️ **Предупреждения** - проблемы с данными (не критичные)
- ❌ **Ошибки** - критические проблемы (если есть)

## 📊 РАБОТА С ДАННЫМИ

### Просмотр сделок

1. Перейдите на вкладку **"Сделки"**
2. Используйте фильтры для поиска нужных данных:

#### Доступные фильтры:

- **Клиент** - поиск по названию клиента
- **Продавец** - фильтр по продавцу
- **Дата счета** - период от и до

#### Сортировка:

- Нажмите на заголовок столбца для сортировки
- Повторное нажатие изменит направление сортировки

### Детальный просмотр сделки

1. Нажмите на номер сделки в таблице
2. Откроется детальная информация:
   - Основные данные сделки
   - Список товаров/услуг
   - История изменений

### Экспорт данных

1. На странице сделок нажмите кнопку **"Экспорт"**
2. Выберите формат: Excel или CSV
3. Файл будет загружен на ваш компьютер

## 🔄 УПРАВЛЕНИЕ СЕССИЯМИ СИНХРОНИЗАЦИИ

1. Перейдите на вкладку **"Сессии"**

Каждая сессия содержит:

- **Длительность** - время обработки
- **Результаты** - количество изменений

### Детали сессии

1. Нажмите на ID сессии для просмотра деталей

## ⚠️ РЕШЕНИЕ ПРОБЛЕМ

### Частые проблемы

#### Файл не загружается

**Возможные причины:**
- Неподдерживаемый формат файла
- Файл слишком большой (>50MB)
- Поврежденный файл

**Решение:**
1. Проверьте формат файла (.xlsx или .xls)
2. Уменьшите размер файла
3. Попробуйте сохранить файл заново

#### Ошибки синхронизации

**Возможные причины:**
- Неправильная структура Excel файла
- Отсутствуют обязательные столбцы
- Некорректные данные в ячейках

**Решение:**
1. Проверьте структуру файла согласно требованиям
2. Убедитесь, что все обязательные столбцы присутствуют
3. Проверьте корректность данных (даты, числа)

#### Медленная работа системы

**Возможные причины:**
- Большой объем данных
- Медленное интернет-соединение
- Высокая нагрузка на сервер

**Решение:**
1. Разделите большой файл на части
2. Попробуйте позже
3. Обратитесь к администратору

### Получение помощи

Если у вас возникли проблемы:

1. **Проверьте раздел "Частые проблемы"** выше
2. **Обратитесь к администратору** системы
3. **Создайте обращение в службу поддержки** с описанием проблемы
