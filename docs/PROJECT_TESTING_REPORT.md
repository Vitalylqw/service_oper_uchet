## 🎯 ЦЕЛЬ ТЕСТИРОВАНИЯ

Комплексная проверка работоспособности системы синхронизации Excel → PostgreSQL с Event Sourcing + CQRS архитектурой, включая:
- Парсинг Excel файлов
- Обнаружение изменений
- Синхронизация с базой данных
- API сервер
- React фронтенд
