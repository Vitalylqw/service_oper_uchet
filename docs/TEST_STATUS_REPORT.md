### ❌ Требующие исправления тесты (9/20)

#### 1. Проблемы с валидацией Pydantic моделей (4 теста)

**Проблема**: Некоторые поля в моделях `Deal` и `DealItem` имеют валидацию, которая не позволяет создавать объекты с пустыми значениями.

**Затронутые тесты**:
- `test_validate_deal_missing_client_name`
- `test_validate_deal_missing_invoice_info`
- `test_validate_item_missing_product_name`
- `test_validate_item_invalid_quantity`

**Решение**: Использовать `model_copy(deep=True)` и устанавливать `None` вместо пустых строк для необязательных полей.

#### 2. Проблемы с логикой валидации Excel файлов (3 теста)

**Проблема**: Новая система валидации Excel файлов изменила поведение для некорректных файлов.

**Затронутые тесты**:
- `test_validate_invalid_file_format`
- `test_validate_excel_read_error`
- `test_validate_deal_no_items`

**Решение**: Адаптировать ожидания тестов под новую логику валидации.

#### 3. Проблемы с созданием ValidationResult (2 теста)

**Проблема**: Тесты пытаются создать `ValidationResult` с неправильными параметрами.

**Затронутые тесты**:
- `test_validation_result_statistics`
- `test_validation_result_filtering`

**Решение**: Исправить создание объектов `ValidationResult` в соответствии с актуальной моделью.

**Старая логика**:

**Новая логика**:
- Комплексная валидация структуры файла
- Детальная проверка листов и заголовков
- Более строгие требования к формату

### 3. Структура ValidationResult

**Актуальная модель**:
```python

    is_valid: bool
    issues: list[ValidationError]
    stats: ValidationStats
```
