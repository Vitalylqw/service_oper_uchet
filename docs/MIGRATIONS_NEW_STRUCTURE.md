## Структура базы данных

### Таблицы

1. **event_store** - Event Sourcing хранилище
   - Все доменные события
   - JSONB данные событий
   - Метаданные и версионность

2. **read_deals** - Денормализованные сделки
   - Основная информация о сделках
   - Финансовые данные
   - Статусы отгрузки и оплаты
   - Вычисляемые поля для проверки

3. **read_positions** - Позиции сделок (упрощенные)
   - Товарные позиции
   - Количество и цены
   - **БЕЗ версионности** (упрощенная структура)
   - CASCADE удаление при удалении сделки
   - **Повышенная точность**: `purchase_price_amount` и `margin_amount` используют NUMERIC(18,5) для сохранения 5 знаков после запятой

4. **read_audit** - Аудит изменений
   - Отслеживание всех изменений
   - Связь с событиями и сессиями

5. **read_stats** - Предвычисленная статистика
   - Агрегированные данные
   - Различные измерения (клиент, продавец, период)

6. **sync_sessions** - Сессии синхронизации
   - Информация о загрузках файлов
   - Статистика и ошибки

### Ключевые особенности

- **PostgreSQL UUID** с SQLite fallback
- **JSONB** для эффективного хранения JSON
- **Комплексная индексация** для производительности
- **Foreign Key CASCADE** для автоматического удаления зависимых данных
- **Денормализация** для быстрых запросов

## Устранение неполадок

### Ошибка "version not found"

Если при запуске `alembic upgrade head` появляется ошибка о неизвестной версии:

```bash
# Проверить текущую версию в БД
python -c "
from src.infrastructure.database.connection import DatabaseManager
import asyncio

async def check():
    async with DatabaseManager().get_session() as session:
        result = await session.execute('SELECT version_num FROM alembic_version')
        print('Current version:', result.scalar())

asyncio.run(check())
"

# Если версия не '0001', обновить вручную
# (ТОЛЬКО если структура БД соответствует новой схеме)
```

## Для разработчиков

### Создание новых миграций

```bash
cd migrations

# Автогенерация миграции
alembic revision --autogenerate -m "Add new feature"

# Проверка миграции
alembic upgrade head --sql  # Просмотр SQL без выполнения

# Применение
alembic upgrade head
```

### Откат миграций

```bash
cd migrations

# Откат к предыдущей версии
alembic downgrade -1

# Полный откат (УДАЛЯЕТ ВСЕ ДАННЫЕ!)
alembic downgrade base
```
