# Документация проекта

Этот каталог содержит только актуальные технические документы. Источники инженерной памяти,
исторические техотчеты и устаревшие материалы вынесены в архив и не должны использоваться как
описание текущего поведения системы.

## Основные документы

| Документ | Назначение |
|----------|------------|
| `../README.md` | Краткий вход в проект и карта документации |
| `DEVELOPMENT_GUIDE.md` | Настройка окружения, тесты, линтинг, рабочие команды |
| `DATABASE_DESIGN.md` | Актуальная схема БД и назначение таблиц |
| `DATABASE_MANAGEMENT.md` | Практическая работа с БД, snapshot и dashboard |
| `MIGRATION_COMMANDS.md` | Команды Alembic и типовые сценарии миграций |
| `POSTGRESQL_SETUP.md` | Поднятие PostgreSQL в dev-среде |
| `../project_progress/PROJECT_OVERVIEW.md` | Карта проекта и навигация по коду |
| `../project_progress/PROJECT_PLAN.md` | Текущий инженерный план |
| `../project_progress/STATUS.md` | Текущее состояние и ближайшие задачи |
| `../project_progress/SYNC_FLOW.md` | Детальный поток синхронизации |
| `../project_progress/DEVELOPMENT_JOURNAL.md` | Хронология значимых изменений |

## Как читать документацию

Если вы впервые заходите в проект:

1. Начните с `../README.md`.
2. Затем откройте `../project_progress/PROJECT_OVERVIEW.md`.
3. Для понимания runtime-потока перейдите в `../project_progress/SYNC_FLOW.md`.
4. Для локальной работы используйте `DEVELOPMENT_GUIDE.md`.

## Что считается актуальным

Актуальной считается документация, которая:

- описывает текущий scope проекта без UI/API/1С как активной функциональности;
- опирается на реальные пути и файлы репозитория;
- не содержит неподтвержденных статусов вроде `Production Ready` или `100%`;
- согласована с кодом в `src/`, миграциями в `migrations/`, тестами в `tests/` и
  проверочными сценариями в `scripts/test/`.

## Архив

Исторические документы и разовые техотчеты собраны в:

- `archive/`
- `../project_progress/archive/`

Если документ нужен для понимания причин старого решения, используйте его как historical context,
но сверяйте итоговые выводы с актуальными документами и кодом.
