# Database Cleanup Scripts

Этот набор скриптов предоставляет функциональность для очистки базы данных SQLite проекта `service_oper_uchet`.

## Файлы

- `clear_database.py` - Основной Python скрипт для очистки базы данных
- `clear_database.bat` - Интерактивный bat файл с меню опций
- `quick_clear_database.bat` - Быстрый bat файл без запросов подтверждения

## Возможности

### Основные функции
- ✅ Очистка всех данных с сохранением структуры схемы
- ✅ Автоматическое создание резервной копии перед очисткой
- ✅ Операция VACUUM для освобождения места на диске
- ✅ Подробное логирование всех операций
- ✅ Статистика до и после очистки
- ✅ Безопасные проверки и подтверждения

### Дополнительные возможности
- 📊 Просмотр статистики базы данных без очистки
- 🔧 Настройка опций через аргументы командной строки
- 📝 Детальное логирование в файл `database_cleanup.log`
- 💾 Автоматическое создание резервных копий с временными метками

## Использование

### 1. Интерактивный запуск (рекомендуется)
```bash
# Запуск с меню опций
clear_database.bat
```

Доступные опции:
1. **Show database statistics only** - только просмотр статистики
2. **Clean database with backup** - очистка с резервной копией (по умолчанию)
3. **Clean database without backup** - очистка без резервной копии
4. **Clean database with auto-confirm** - очистка без запросов подтверждения

### 2. Быстрая очистка
```bash
# Быстрая очистка с автоматическим подтверждением
quick_clear_database.bat
```

### 3. Прямой запуск Python скрипта
```bash
# Просмотр статистики
python clear_database.py --stats-only

# Очистка с резервной копией (с подтверждением)
python clear_database.py

# Очистка без резервной копии
python clear_database.py --no-backup

# Очистка с автоматическим подтверждением
python clear_database.py --confirm
```

## Аргументы командной строки

| Аргумент | Описание |
|----------|----------|
| `--no-backup` | Пропустить создание резервной копии |
| `--confirm` | Пропустить запрос подтверждения |
| `--stats-only` | Только показать статистику базы данных |

## Структура резервных копий

Резервные копии сохраняются в папке `data/backup/` с именем:
```
service_oper_uchet_backup_YYYYMMDD_HHMMSS.sqlite
```

## Логирование

Все операции записываются в файл `database_cleanup.log` в папке `data/` с подробной информацией:
- Время выполнения операций
- Количество удаленных строк
- Размер базы данных до и после
- Список очищенных таблиц
- Ошибки (если возникают)

## Безопасность

### Меры предосторожности
- ⚠️ **ВНИМАНИЕ**: Скрипт удаляет ВСЕ данные из базы данных
- 🔒 Автоматическое создание резервной копии перед очисткой
- ✅ Запрос подтверждения перед удалением (если не указан `--confirm`)
- 📋 Подробная статистика для контроля операций

### Рекомендации
1. **Всегда используйте резервные копии** (по умолчанию включено)
2. **Проверяйте статистику** перед очисткой
3. **Сохраняйте логи** для отслеживания операций
4. **Тестируйте на копии** перед использованием на продакшене

## Устранение неполадок

### Ошибки и решения

1. **Database file not found**
   - Убедитесь, что файл `service_oper_uchet.sqlite` находится в папке `data/`

2. **Permission denied**
   - Запустите скрипт от имени администратора
   - Проверьте права доступа к файлу базы данных

3. **Virtual environment not found**
   - Скрипт автоматически найдет и активирует виртуальное окружение
   - Если не найдено, убедитесь что оно создано в корне проекта

4. **Backup creation failed**
   - Проверьте права на запись в папку `data/backup/`
   - Убедитесь в наличии свободного места на диске
