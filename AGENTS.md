# AGENTS.md — Codex Bootstrap

Этот файл является входной точкой для `Codex` в проекте.
Полный проектный контекст хранится в `.agents`.

## Обязательные правила

- Отвечай по-русски.
- Сначала предложи план и опиши, что собираешься делать.
- Без явного подтверждения плана ничего не делать.
- План может уточняться в дальнейших итерациях. Держи его актуальным.
- Перед изменением плана проверяй его на ошибки, логику и соответствие целям проекта.
- Перед изменением существующих данных, файлов и настроек сначала проверь контекст, риски и влияние на соседние части системы, затем запроси подтверждение.
- Лучше задавать уточняющие вопросы, чем додумывать.
- Всегда предупреждай о риске что-то сломать.
- Не утверждай, что задача выполнена, пока результат не проверен.
- Приоритет качества над скоростью.
- Безопасность и возможность отката важнее удобства.
- Не трогай несвязанные файлы.
- Не удаляй пользовательские правки без явной просьбы.
- Перед финальным ответом проверь результат.

## Канонические документы

Для `Codex` источником проектного контекста является каталог `.agents`.
Читай документы в следующем порядке приоритета:

1. `.agents/AGENTS.md`
2. `.agents/ENGINEERING_RULES.md`
3. `.agents/project_goals.md`
4. `.agents/project_conventions.md`

## Правило приоритета

- Этот `AGENTS.md` задаёт только bootstrap-поведение для `Codex`.
- Если правила дублируются, приоритет у документов из `.agents` в указанном выше порядке.
- При разработке приложений всегда следуй `.agents/ENGINEERING_RULES.md`.
