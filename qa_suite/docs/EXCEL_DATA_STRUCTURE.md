# Структура данных Excel файла

## 1. Общая структура книги

- Каждый лист Excel = один период (месяц + год)
- Название листа парсится как период: `"Май 2025"`, `"Январь 2024"`
- Добавление/удаление листа = добавление/удаление данных за период

## 2. Структура листа

### 2.1 Заголовочная строка

Первая строка содержит заголовки столбцов:

| Индекс | Столбец | Название | Описание |
|--------|---------|----------|----------|
| 0 | A | Клиент | Название клиента |
| 1 | B | Счет | Информация о счете (номер + дата) |
| 2 | C | Отгружен | Статус отгрузки ("да"/"нет") |
| 3 | D | УПД | Номер УПД |
| 4 | E | Оплачен | Статус оплаты ("да"/"нет") |
| 5 | F | Выручка | Общая выручка по сделке |
| 6 | G | Маржа | Общая маржа по сделке |
| 7 | H | Продавец | Имя продавца |
| 8 | I | Себест. | Общая себестоимость |
| 9 | J | Откат | Сумма отката |

### 2.2 Master-запись (Deal)

Строка сделки - содержит заполненный столбец "Клиент":

```
| ЛЕНТЕХСТРОЙ | 5938 от 16.06.2025 | нет | | нет | 145270 | 29713.68 | КРЕПЕЖ-ИНСТРУМЕНТ ООО | 30536.32 | |
```

### 2.3 Detail-записи (DealItem)

Строки позиций - столбец "Клиент" пустой:

```
| | Нож строительный КВТ | 20 | 100.50 | 356 | 7120 | 2840 | | 1005 | этм | 18 |
```

Индексы для DealItem:

| Индекс | Столбец | Поле | Описание |
|--------|---------|------|----------|
| 1 | B | product_name | Название товара |
| 2 | C | quantity | Количество |
| 3 | D | purchase_price | Цена закупки (5 знаков после запятой) |
| 4 | E | sale_price | Цена продажи |
| 5 | F | revenue | Выручка позиции |
| 6 | G | margin | Маржа позиции |
| 8 | I | cost | Себестоимость позиции |
| 9 | J | supplier_name | Поставщик |
| 10 | K | pickup_date | Дата забора |

## 3. Ключевые идентификаторы

### 3.1 deal_key (уникальный ключ сделки)

Формируется из:
- invoice_number (номер счета)
- invoice_date (дата счета)
- seller (продавец)
- period (период)

```python
deal_key = f"{invoice_number}|{invoice_date}|{seller}|{period}".lower()
# Пример: "5938|16.06.2025|крепеж-инструмент ооо|май 2025"
```

### 3.2 item_key (уникальный ключ позиции)

Формируется через hash от:
- position_number
- product_name
- deal_key
- все финансовые поля

```python
item_key = get_full_hash_key(deal_key).value
```

## 4. Правила парсинга

### 4.1 Определение типа строки
- Если столбец A (Клиент) заполнен - это Deal (master)
- Если столбец A пустой - это DealItem (detail)

### 4.2 Связь позиций со сделкой
- Позиции следуют непосредственно после строки сделки
- Позиции относятся к последней найденной сделке
- position_number назначается автоматически (1, 2, 3...)

### 4.3 Парсинг invoice_info

Формат: `"НОМЕР от ДАТА"`, например `"5938 от 16.06.2025"`

```python
parts = invoice_info.split(" от ")
invoice_number = parts[0].strip()
invoice_date = parts[1].strip() if len(parts) > 1 else ""
```

### 4.4 Парсинг статусов

| Значение в Excel | Статус в БД |
|-----------------|-------------|
| "да", "yes", "1", True | completed |
| "нет", "no", "0", False | pending |
| пусто, None | pending |

## 5. Формулы

Excel файл может содержать формулы для вычисления:
- Выручка = quantity * sale_price
- Себестоимость = quantity * purchase_price
- Маржа = revenue - cost

При парсинге формулы вычисляются через xlcalculator.
