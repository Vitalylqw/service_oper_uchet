# Техническое задание: QA Suite

## 1. Назначение

QA Suite - изолированный стенд для интеграционного тестирования логики синхронизации данных из Excel в базу данных PostgreSQL. Стенд проверяет корректность работы системы детектирования изменений и обновления read-моделей.

## 2. Функциональные требования

### 2.1 Генерация Excel файлов
- Программное создание Excel файлов с заданной структурой
- Модификация существующих файлов (добавление/удаление листов, сделок, позиций)
- Изменение отдельных полей сделок и позиций

### 2.2 Управление базой данных
- Полная очистка тестовых данных
- Создание снапшотов состояния БД
- Сбор агрегатных метрик для контроля целостности

### 2.3 Выполнение тестов
- Загрузка сценариев из YAML конфигурации
- Последовательное выполнение сценариев
- Интеграция с SyncOrchestratorService

### 2.4 Валидация результатов
- Проверка количества изменений (INSERT/UPDATE/DELETE)
- Проверка состояния БД после синхронизации
- Проверка созданных событий
- Контроль агрегатных показателей

### 2.5 Отчетность
- Генерация JSON отчетов
- Генерация HTML отчетов
- Сохранение истории прогонов

## 3. Технический стек

| Компонент | Технология |
|-----------|------------|
| Язык | Python 3.11+ |
| База данных | PostgreSQL |
| ORM | SQLAlchemy 2.0 (async) |
| Excel | openpyxl |
| Конфигурация | PyYAML, pydantic-settings |
| Логирование | loguru |
| Валидация | Pydantic v2 |

## 4. Архитектура

```
qa_suite/
  config/           # Конфигурация и настройки
    settings.py     # Pydantic Settings класс
  core/             # Ядро системы
    models.py       # Pydantic модели данных
    excel_builder.py    # Генерация Excel
    db_manager.py       # Управление БД
    scenario_loader.py  # Загрузка сценариев
    test_runner.py      # Исполнитель тестов
    validators.py       # Валидация результатов
    reporters.py        # Генерация отчетов
  docs/             # Документация
  tests/            # Тестовые данные
    scenarios/      # YAML сценарии
    fixtures/       # Базовые Excel файлы
  reports/          # Выходные отчеты
  scripts/          # Скрипты запуска
```

## 5. Интеграция с основным проектом

QA Suite использует существующие компоненты из `src/`:

- `SyncOrchestratorService` - оркестрация синхронизации
- `ChangeDetectorService` - детектирование изменений
- `ExcelParserService` - парсинг Excel файлов
- `ReadModelBuilder` - обновление read-моделей
- `DatabaseManager` - управление соединениями БД

## 6. Таблицы БД для проверки

| Таблица | Описание |
|---------|----------|
| read_deals | Сделки (read-модель) |
| read_positions | Позиции товаров |
| event_store | Хранилище событий |
| read_audit | Аудит изменений |
| sync_sessions | Сессии синхронизации |

## 7. Требования к окружению

- PostgreSQL 13+
- Python 3.11+
- Доступ к БД с правами на CRUD операции
- Конфигурация через config.env или переменные окружения

## 8. Ограничения

- Тесты выполняются последовательно (один сценарий за раз)
- Необходима изоляция тестовой БД от продуктивной
- Временные файлы Excel очищаются после прогона
