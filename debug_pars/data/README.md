# Скрипты анализа базы данных

Коллекция скриптов для анализа и просмотра данных в таблицах `read_deals` и `read_positions`.

## 📊 Список скриптов

### 1. Общая информация о БД
**`db_info_report.py`** - Основная статистика по таблицам
- Количество записей и уникальных значений
- Суммы по финансовым полям
- Быстрый обзор состояния БД

**Запуск:**
```bash
python debug_pars/data/db_info_report.py
# или
debug_pars/data/db_info_report.bat
```

### 2. Анализ распределения Hash Keys
**`hash_key_distribution_analysis.py`** - Анализ уникальности hash_key
- Распределение по количеству вхождений
- Примеры хешей с разным количеством дублей
- Выявление паттернов дублирования

**Запуск:**
```bash
python debug_pars/data/hash_key_distribution_analysis.py
# или
debug_pars/data/hash_key_distribution_analysis.bat
```

### 3. Анализ дублирования записей
**`duplication_analysis.py`** - Детальный анализ дублей
- Сравнение дублированных записей
- Поиск различий в бизнес-полях
- Статистика версионности и активности

**Запуск:**
```bash
python debug_pars/data/duplication_analysis.py
# или
debug_pars/data/duplication_analysis.bat
```

### 4. Просмотр таблицы позиций
**`view_positions_table.py`** - Интерактивный просмотр данных
- Табличный вывод всех записей
- Фильтрация по различным полям
- Экспорт в CSV и JSON

**Режимы запуска:**
```bash
# Интерактивный режим (по умолчанию)
python debug_pars/data/view_positions_table.py --interactive
# или
debug_pars/data/view_positions_interactive.bat

# Быстрый просмотр N записей
python debug_pars/data/view_positions_table.py --quick 50
# или
debug_pars/data/view_positions_quick.bat
```

### 5. Экспорт в Excel
**`export_positions_excel.py`** - Полный экспорт в Excel
- Все записи в структурированном виде
- Статистические сводки
- Анализ дублирования на отдельном листе

**Запуск:**
```bash
python debug_pars/data/export_positions_excel.py
# или
debug_pars/data/export_positions_excel.bat
```

## 🔍 Основные находки

### Критическая проблема: Троекратное дублирование
- **Все** 1,730 уникальных hash_key встречаются ровно **3 раза**
- Общее количество записей: 5,190 (1,730 × 3)
- **Проблема:** Одинаковые позиции попадают в разные сделки (разные deal_id)

### Выявленные аномалии:
1. **Нарушение уникальности:** Позиции с одинаковым содержимым имеют разные position_number
2. **Искажение данных:** Одна позиция учитывается в 3 разных сделках
3. **Финансовые ошибки:** Выручка считается трижды для одной и той же позиции
