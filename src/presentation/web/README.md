# React Dashboard - Система Операционного Учета

## 🎯 Sprint 2.2 - React Dashboard (ЗАВЕРШЕН!)

Современный веб-интерфейс для системы операционного учета, построенный на React 18 + TypeScript + Vite.

## ✨ Реализованная функциональность

### 🔐 Аутентификация
- Форма входа с JWT токенами
- Role-based access control (RBAC)
- Автоматическое перенаправление при истечении сессии
- Демо-пользователи для тестирования

### 📊 Dashboard
- Карточки статистики с real-time данными
- Список последних сделок
- Мониторинг сессий синхронизации
- Статус здоровья системы

### 📄 Сделки
- Таблица с пагинацией
- Фильтрация по ИНН, контрагенту, статусу
- Адаптивный дизайн
- Сортировка и поиск

### 🔄 Синхронизация
- Мониторинг сессий синхронизации
- Возможность запуска новых сессий (admin/analyst)
- История операций с детальной информацией
- Фильтрация по типу и статусу

## 🛠️ Технологический стек

### Frontend
- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Vite** - build tool и dev server
- **TanStack Query** - управление состоянием сервера
- **Zustand** - клиентское состояние
- **Axios** - HTTP клиент
- **React Router** - маршрутизация

### Тестирование
- **Vitest** - test runner
- **React Testing Library** - тестирование компонентов
- **Happy DOM** - DOM environment для тестов

### Стилизация
- **CSS Modules** - изолированные стили
- **Responsive Design** - адаптивность
- **CSS Grid & Flexbox** - современная верстка

## 🚀 Запуск разработки

### Установка зависимостей
```bash
cd src/presentation/web
npm install
```

### Запуск dev сервера
```bash
npm run dev
```
Приложение будет доступно по адресу http://localhost:3000

### Proxy настройка
Vite автоматически проксирует API запросы на FastAPI backend:
- `/api/*` → `http://localhost:8000`
- `/auth/*` → `http://localhost:8000`
- `/health/*` → `http://localhost:8000`

## 🔗 API Интеграция

### Эндпоинты
- `GET /api/v1/deals/` - список сделок
- `GET /api/v1/deals/stats` - статистика сделок
- `GET /api/v1/sessions/` - сессии синхронизации
- `POST /api/v1/sessions/` - создание сессии
- `POST /auth/login` - аутентификация
- `GET /health/` - статус системы

### Типизация
Все API ответы полностью типизированы с использованием TypeScript интерфейсов.

## 👥 Роли пользователей
