# СИСТЕМА ТЕСТИРОВАНИЯ SERVICE_OPER_UCHET

## 📋 ОПИСАНИЕ

Комплексная система тестирования для проверки работоспособности проекта service_oper_uchet. Включает тесты всех компонентов: база данных, Excel парсинг, синхронизация, API сервер, React фронтенд.

## 🚀 БЫСТРЫЙ СТАРТ

### 1. Запуск всех тестов
```bash
# Windows PowerShell
.\run_all_tests.bat

# Или по отдельности:
.\test_database.bat
.\test_excel_parsing.bat
.\test_sync_integration.bat
.\test_api_server.bat
.\test_frontend.bat
```

### 2. Запуск серверов для тестирования
```bash
# API сервер
.\start_api_server.bat

# React UI
.\start_react_ui.bat
```

## 🚨 УСТРАНЕНИЕ ПРОБЛЕМ

### API сервер не запускается
```bash
# Проверить, что порт 8000 свободен
netstat -an | findstr :8000

# Запустить в обычном режиме для диагностики
python -m uvicorn src.presentation.api.main:app --host 127.0.0.1 --port 8000
```

### React UI не доступен
```bash
# Проверить, что порт 3000 свободен
netstat -an | findstr :3000

# Перейти в папку web и запустить
cd src/presentation/web
npm start
```

### Ошибки импорта
```bash
# Убедиться, что src добавлен в PYTHONPATH
set PYTHONPATH=%PYTHONPATH%;%CD%\src
```

## 📝 ЛОГИ

Все тесты создают подробные логи с использованием loguru. Логи выводятся в консоль с цветовой маркировкой:
- 🔍 INFO - информационные сообщения
- ✅ SUCCESS - успешные операции
- ⚠️ WARNING - предупреждения
- ❌ ERROR - ошибки

## 🎯 РЕКОМЕНДАЦИИ

1. **Регулярное тестирование**: Запускайте тесты после каждого значительного изменения
2. **Мониторинг логов**: Обращайте внимание на предупреждения и ошибки
3. **Обновление данных**: Регулярно обновляйте тестовые данные в Excel файле
4. **Резервное копирование**: Делайте бэкап базы данных перед тестированием
