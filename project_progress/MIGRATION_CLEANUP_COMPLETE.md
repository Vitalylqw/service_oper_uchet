## Схема базы данных

### Таблицы:
1. **event_store** - Event sourcing хранилище
2. **read_deals** - Денормализованные сделки  
3. **read_positions** - Позиции сделок (упрощенные, без версионности)
4. **read_audit** - Аудит изменений
5. **read_stats** - Предвычисленная статистика
6. **sync_sessions** - Сессии синхронизации

### Ключевые особенности:
- PostgreSQL UUID типы с SQLite fallback
- JSONB для хранения событий
- CASCADE удаление позиций при удалении сделок
- Комплексная индексация для производительности
- Упрощенная структура позиций без версионности
