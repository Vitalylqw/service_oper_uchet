# Архив project_progress

Этот каталог содержит historical project notes и разовые техотчеты.

Правила использования:

- файлы здесь не являются текущим описанием проекта;
- они нужны для сохранения причин старых решений и этапов эволюции;
- активными документами остаются только:
  - `project_progress/PROJECT_OVERVIEW.md`
  - `project_progress/PROJECT_PLAN.md`
  - `project_progress/STATUS.md`
