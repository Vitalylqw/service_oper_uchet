# Хронологический журнал изменений

## 2025-08-18 - Миграция на Ubuntu

### Проблема
Проект перенесен с Windows на Ubuntu, требуется адаптация для работы через dev-container в Cursor.

### Анализ
- Проект использовал Windows .bat файлы
- Dev-container был настроен для Ubuntu
- Архитектура включала web-часть, которая пока не нужна

### Решение
Создана простая архитектура для backend разработки:

1. **Dev-container исправлен** - убран Node.js, оставлен только Python
2. **Скрипты упрощены** - созданы Linux-совместимые .sh файлы
3. **Web-часть убрана** - будет добавлена после завершения backend
4. **Архитектура очищена** - только backend + БД

### Результат
- Простая рабочая среда для backend разработки
- Dev-container с Python окружением
- Отдельный PostgreSQL контейнер
- Простые скрипты запуска
- Готовая документация для Ubuntu

### Файлы созданы/изменены
- `scripts/services/start_backend.sh` - запуск backend
- `scripts/services/start_from_host.sh` - запуск с хоста
- `README_UBUNTU.md` - документация для Ubuntu
- `.devcontainer/devcontainer.json` - исправлен
- Удалены ненужные web-скрипты

### Следующие шаги
- Завершить backend разработку
- Добавить web-часть в отдельном контейнере
- Создать полную docker-compose для production
